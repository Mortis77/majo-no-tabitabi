# cast:heroine — as built

## Summary
The four model and animation files described below are under `assets/models/chars/`. All four passed a glbview check.

1. char_akari.glb is the heroine, built from HairSample_Female (CC0). She is 1.551 m tall (scale baked into the geometry), stands on y=0 facing +Z, has 27,164 triangles and 2.2 MB, with 12 textures at 1024 px or less. She has a white top, vermilion skirt, red collar/cuffs/waist ribbon, dark hair, a red bow on the back of the head (picked over twin bows because it reads well from the game camera behind her) and red modesty shorts. The file has no clips and keeps 13 expression morphs.
2. anim_ual.glb holds all 84 clips from Universal Animation Library 1 + 2, retargeted onto the VRoid skeleton. It contains skeleton nodes only, no mesh. Clips play in place (hips x/z locked, y kept), and every *_Loop clip has its first and last frames matched (the mismatch was 1.3° at most). Clip names are unchanged.
3. prop_gohei.glb (226 tris) and prop_broom.glb (1.6 m, 2,756 tris) are original props generated by a script.

Spot checks by eye looked sane: feet on the ground, limbs and fingers fine. Low-angle views of sitting, roll, jump, swim, death and crouch show only the red shorts. The back view and the toon-material view also look right.

Pipeline changes: convert_vroid.mjs gained a `--scale` option, ribbon.mjs follows that scale, retarget.mjs gained `--lock-xz` and the loop seam fix, and pv.mjs gained low camera angles. props.mjs and manifest.mjs are new. NOTES.md is up to date.

## Public API
The manifest is assets/_incoming/protagonist/manifest.fragment.json. It has four entries; each carries file, type "model", license "CC0", author, source, scale 1, size, tris and notes.

- char_akari: file models/chars/char_akari.glb, size [1.301, 1.551, 0.442], tris 27164, clipsFrom "anim_ual".
  - morphs: [blink, blink_l, blink_r, joy, fun, angry, sorrow, surprised, a, i, u, e, o], on the mesh "akari_face" (names are in mesh.extras.targetNames).
  - bones: head J_Bip_C_Head, chest J_Bip_C_Chest, upperChest J_Bip_C_UpperChest, spine J_Bip_C_Spine, hips J_Bip_C_Hips, handR J_Bip_R_Hand, handL J_Bip_L_Hand, neck J_Bip_C_Neck, footR/footL J_Bip_R_Foot / J_Bip_L_Foot.
  - hipsHeight: 0.887 m. The rest pose is a T-pose.
  - Materials are plain metal-rough, meant to be re-shaded with the game's toon material. The Ribbon material has extras.shadeColor.
- anim_ual: file models/chars/anim_ual.glb, tris 0. The scene is the node tree Root > J_Bip_* (no mesh).
  - clips: an array of 84 entries {name, duration (s), loop (bool), desc}. A_TPose is dropped; all other names match the library.
  - Tracks are rotations plus one translation on J_Bip_C_Hips.
  - Hips y is absolute for hipsHeight 0.887 m. For another VRoid character, multiply the hips position track's y by (that character's hipsHeight / 0.887).
  - Swim clips treat y=0 as the water line. Sitting_Idle_Loop and Driving_Loop put the hips at 0.52 m.
  - Proposed game mapping (also written in notes):
    - idle: Idle_Loop; walk: Walk_Loop; run: Jog_Fwd_Loop; sprint: Sprint_Loop
    - jump: Jump_Start; fall: Jump_Loop; land: Jump_Land; dodge: Roll
    - cast_throw: Spell_Simple_Shoot (OverhandThrow as an alternative)
    - cast_raise: Spell_Simple_Enter, then Spell_Simple_Idle_Loop (the library has no overhead raise)
    - cast_channel: Spell_Simple_Idle_Loop; cast_summon: Farm_PlantSeed
    - guard: Idle_Shield_Loop (enter with Shield_OneShot, broken with Idle_Shield_Break)
    - hit: Hit_Chest / Hit_Head (light), Hit_Knockback (heavy); death: Death01 (LayToIdle to get back up)
    - sit_broom: Driving_Loop (Sitting_Idle_Loop as an alternative); swim: Swim_Fwd_Loop / Swim_Idle_Loop
    - interact: Interact; cheer: Yes (Dance_Loop for a celebration loop); talk: Idle_Talking_Loop
- prop_gohei: file models/props/prop_gohei.glb. Origin is the grip, the stick runs along +Y, total length 0.5 m. Node extras {attach: "handR"}.
- prop_broom: file models/props/prop_broom.glb. 1.6 m along Z, front tip at +Z, origin at the riding seat. Node extras.lanternLight gives the lantern centre for a point light, and the LanternPaper material has a warm emissive.

Script changes in .tmp/protagonist:
- convert_vroid.mjs: new `--scale k` option.
- retarget.mjs: new `--lock-xz` flag; *_Loop clips are seam-fixed automatically.
- pv.mjs: new views lf, lb, ls, u (low camera angles).
- props.mjs <outDir>: builds the two props.
- manifest.mjs: writes the manifest fragment.

## Known issues
- tools/glbview.mjs (the project's own copy) fails headless with "ReferenceError: view is not defined". Its iife bundle needs `define: {'import.meta.url': '"http://127.0.0.1/"'}` in the esbuild.build call. tools/ was left untouched; all checks used the fixed copy at tools/devkit/protagonist/glbview.mjs.
- The library's hips y is absolute for a hips height of 0.887 m. Other VRoid characters need their hips position track scaled (see the manifest notes), otherwise they will float or sink.
- Locking hips x/z makes travelling clips (Roll, Death01, Hit_Knockback, Slide_*, Sword_Dash) play in place, so the game must move the character itself. Feet slide slightly in those clips.
- The skirt has no cloth bones and is skinned to the thighs, so it clips through the legs a little in deep sitting or crouching poses. Modesty is unaffected.
- The library has no overhead arm-raise clip or dedicated cheer clip. The proposed mapping substitutes Spell_Simple_Enter and Yes / Dance_Loop.
- The prop attach rotations (gohei in the hand, broom under the hips while riding) have not been fitted in the game yet.
